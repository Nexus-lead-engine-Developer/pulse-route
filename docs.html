3-Minute Webhook Integration Guide

Connect any client sub-account from GoHighLevel, Make, Zapier, or Meta Lead Ads to PulseRoute in three steps.

1. Your Endpoint URL

Send a POST request with Content-Type: application/json to your assigned agency webhook URL:

POST https://netlify.app

2. JSON Payload Fields

FieldTypeRequiredExample
nameStringYes"James Miller"
phoneString (UK Mobile)Yes"07700900123" or "+447700900123"
postcodeStringOptional"OX1 2JD"
 
{
  "name": "James Miller",
  "phone": "07700900123",
  "postcode": "OX1 2JD"
}

3. Plug-and-Play Platform Setup

GoHighLevel (GHL): Workflow Trigger (Facebook Lead Form Submitted) → Action: Webhook (POST) → paste your URL and map name, phone, and postcode.

Make / Zapier: Trigger (New Lead) → Action: HTTP Make a Request / Webhooks by Zapier (POST JSON) → paste URL and map fields.
